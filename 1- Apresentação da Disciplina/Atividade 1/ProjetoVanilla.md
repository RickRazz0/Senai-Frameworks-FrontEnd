# 🎮 Atividade 01 — Endless Runner (Vanilla JS)

Projeto desenvolvido para a disciplina **Frameworks Front-end**, utilizando apenas **HTML**, **CSS** e **JavaScript (Vanilla JS)**.

## 📖 Sobre

O objetivo desta atividade é desenvolver um jogo simples utilizando JavaScript puro, colocando em prática conceitos fundamentais do desenvolvimento Front-end, além de utilizar Git/GitHub para versionamento e realizar o deploy da aplicação na Vercel.

---

## 🎯 Objetivo do Jogo

Controlar um carrinho que deve desviar dos obstáculos para sobreviver o maior tempo possível.

---

## 🕹️ Funcionalidades

- Movimentação entre três faixas
- Obstáculos gerados aleatoriamente
- Sistema de colisão
- Pontuação em tempo real
- Recorde salvo no navegador
- Tela de Game Over
- Reinício da partida

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
