
# Resumo da Aula 01: Apresentação da Disciplina e Contextualização

## 1. Contexto do Desenvolvimento Front-end

* **O que é Front-end:** É a camada da aplicação com a qual o usuário interage diretamente. Responsável pela interface visual, experiência do usuário (UX) e comunicação com os sistemas de processamento de dados (Back-end).


* **Importância dos Frameworks:** A utilização de frameworks é essencial no mercado atual para criar interfaces rápidas, organizadas e de fácil manutenção, atuando como um requisito estratégico para a competitividade das empresas.



## 2. Conceitos Técnicos Discutidos

* **Arquitetura e Escopo do Site:** Engloba a definição de escopo, prototipação, UX/UI, validação de usabilidade e versionamento com deploy.


* **JavaScript Puro (Vanilla JS):** Linguagem de script interpretada e sem dependências externas. Base essencial para a manipulação do DOM, comunicação com servidores e compreensão das abstrações fornecidas pelos frameworks.


* **Frameworks Front-end:**
* **Conceitos centrais:** Componentização (reutilização e organização de código), gerenciamento de estado, roteamento e integração com APIs.


* **Principais tecnologias apresentadas:** React, Vue e Angular.





## 3. Estrutura e Objetivos da Disciplina

* **Conteúdo Programático:** Estudo do ambiente de desenvolvimento, frameworks CSS e Front-end, componentização, boas práticas e deploy de aplicações.


* **Competências Finais:** Capacitar o estudante a desenvolver interfaces modernas, criar aplicações completas com frameworks Front-end, utilizar Git/GitHub e realizar a publicação (deploy) da aplicação na web.


* **Importância do Portfólio:** Serve como evidência concreta do aprendizado, facilita a avaliação e amplia as oportunidades de inserção no mercado de trabalho.



## 4. Metodologia de Ensino e Avaliação

* **Metodologia:** Aulas expositivas dialogadas, discussões críticas, estudos de caso e conexão entre teoria e prática profissional.


* **Critérios de Avaliação:**
* **55% Avaliação Docente:** Divididos em Desenvolvimento do Projeto (20%), Apresentação do Projeto (20%) e Realização das atividades (15%).


* **35% Projeto Integrador**.


* **10% Autoavaliação**.




* **Projeto Final:** Elaboração de uma documentação completa do projeto no formato de "mini TCC", cobrindo etapas desde a concepção, planejamento e execução até resultados, análise crítica e benchmarking.



## 5. Atividades Propostas

1. **Atividade 01:** Criação de um projeto em Vanilla JS (HTML, CSS e JavaScript), integração do ambiente de desenvolvimento (IDE) com o GitHub e deploy da aplicação via Vercel.


2. **Atividade 02 (em grupo de 3 a 5 alunos):**
* Criação do repositório principal no GitHub contendo um arquivo Markdown (`.md`) com o resumo da Aula 01.


* Elaboração de um relatório técnico em PDF (mínimo de 5 páginas) sobre um Framework Front-end escolhido, detalhando características, vantagens, aplicações de mercado e um exemplo prático.
