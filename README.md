# 📊 Critérios de Avaliação

| Componente | Peso |
| --- | --- |
| Avaliação Docente | 55% |
| &nbsp;&nbsp;↳ Desenvolvimento de Projeto | 20% |
| &nbsp;&nbsp;↳ Apresentação do Projeto | 20% |
| &nbsp;&nbsp;↳ Realização das atividades | 15% |
| Projeto Integrador | 35% |
| Autoavaliação | 10% |

- **Desenvolvimento de Projeto:** documentação completa elaborada como um "mini TCC", abordando planejamento, execução, resultados, desafios, soluções e análise crítica.
- **Apresentação do Projeto:** foco no processo de gestão, organização do backlog, páginas desenvolvidas e benchmarking, destacando funcionalidades e comparações com o mercado.
